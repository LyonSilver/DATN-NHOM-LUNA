# Gilded Fantasy UI Kit — LITE (free sample)

A free sample of the full Gilded Fantasy UI Kit: 1 panel (9-slice, border 72 px), 5 buttons, bar frame + trough + HP fill,
4 slots, 4 icons, 2 rank emblems, 1 coin and a medallion/crest/close button. Same quality as the full kit.

The full kit has 80 assets: 24 buttons, 5 bar colors, 6 slots, 16 icons, 7 ranks, coins, VFX flipbooks.

Roblox: panel -> ImageLabel, ScaleType = Slice, SliceCenter = Rect(72, 72, 184, 184).
