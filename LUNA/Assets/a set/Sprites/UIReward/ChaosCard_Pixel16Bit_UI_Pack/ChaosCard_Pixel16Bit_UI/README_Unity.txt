CHAOS CARD - 16-BIT PIXEL UI PACK

Includes 15 transparent sprites + 1 full-screen reference processed from your original UI graphics.
Each PNG retains its original canvas size; 15 sprites have transparent backgrounds.
The full RESULT screen is a reference/mockup and is not transparent.

UNITY 6 IMPORT RECOMMENDATIONS
1. Select imported PNG assets and set Texture Type = Sprite (2D and UI).
2. Set Filter Mode = Point (no filter).
3. Set Compression = None to prevent blocky compression artifacts.
4. Set Max Size high enough for each sprite (e.g. 2048 or 4096 for the reference).
5. In Image component, enable Preserve Aspect when appropriate.
6. For UI banners that should stretch, set Sprite Editor borders and use Image Type = Sliced (9-slice), not Simple stretching if corners distort.

NOTE: 16-bit here describes classic 16-bit console-style pixel graphics, NOT 16x16-pixel canvases.
These are algorithmically pixel-stylized versions of the uploaded assets, rather than hand-redrawn sprites.
Original English lettering (where present) is retained from the originals and pixelated.
