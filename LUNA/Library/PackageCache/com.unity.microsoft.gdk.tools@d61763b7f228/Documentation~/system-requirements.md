# System requirements and installation

Understand the system requirements and installation instructions to set up the Microsoft GDK Tools package.



## Requirements
Understand the system requirements before you install the Microsoft GDK Tools package for Unity (com.unity.microsoft.gdk.tools).

### Microsoft GDK
To use the Microsoft GDK Tools package, you must use the Microsoft Game Development Kit (GDK). There are two options:

1. Install the Microsoft Game Development Kit (GDK). This is the recommended approach, refer to [Game Development Kit (GDK) documentation](https://learn.microsoft.com/en-us/gaming/gdk/).
2. Build Without Install (BWOI). This is for advanced users, refer to [Using the Microsoft Game Development Kit without installation](build-without-install.md).
### Unity Editor requirements

It’s recommended to use the latest version of the editor stream you're currently using. This package is supported from Unity Editor version 2022.3 and newer.

> [!NOTE]
> The Microsoft GDK Tools package is supported only on Unity Editor for Windows.

## Install the Microsoft GDK Tools package
To install the Microsoft GDK Tools package (com.unity.microsoft.gdk.tools), follow the instructions in the [Package Manager](https://docs.unity3d.com/Manual/Packages.html) documentation.

### Recommended package

It’s recommended to use the Microsoft GDK Tools package (com.unity.microsoft.gdk.tools) with the Microsoft GDK API package (com.unity.microsoft.gdk).

## Supported features

The Microsoft GDK Tools package provides:
* Access to the GDK Settings and Game Configuration files directly within the Unity Editor.
* Support for [localized shell visuals](https://learn.microsoft.com/en-us/gaming/gdk/_content/gc/system/overviews/microsoft-game-config/microsoftgameconfig-localization).
* Tools to build a Microsoft Store package to the required GDK specifications.
