# Microsoft GDK Discovery Sample: Simple GDK Discovery

This sample shows basic usage of the Microsoft GDK Discovery API.

After importing this sample new menu items will be added to the Editors main menu '**GDK** > **Discovery Samples** > **...**'.

Each menu item demonstrates an aspect of the API and corresponds with a '.cs' file in the sample. Output from selecting the menu item will be reflected in the Editor console window.
