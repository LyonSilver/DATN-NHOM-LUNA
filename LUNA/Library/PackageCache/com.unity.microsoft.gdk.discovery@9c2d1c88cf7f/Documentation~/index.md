# Microsoft GDK Discovery package

The Microsoft GDK Discovery package provides APIs which you can use to access the details of the Microsoft GDK SDKs and related SDKs available on your system. 

The package is intended to be used with the Microsoft Game Development Kit (GDK). 
The package finds and enumerates GDKs which have been installed through the regular Microsoft installer, and also a GDK which have been set up using Microsoft's build without install method.

For more information on the build without install method, refer to the Microsoft documentation on [Build without install overview](https://learn.microsoft.com/en-us/gaming/gdk/_content/gc/tools-console/usingwithoutinstall/withoutinstall-overview#build-without-install-overview).
